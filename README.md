📌 Project Overview

Recipe Finder is a responsive web application that allows users to:

🔍 Search meals by name

📖 View detailed recipe instructions

🎥 Watch recipe videos (YouTube)

❤️ Add or remove meals from favorites

💾 Store favorites using browser LocalStorage

The application fetches real-time data from TheMealDB API.
